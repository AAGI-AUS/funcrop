# Plot method for fda_comparison

Produces overlay plots of coefficient functions from competing models
for visual comparison, plus a metric comparison bar chart.

## Usage

``` r
# S3 method for class 'fda_comparison'
plot(x, ...)
```

## Arguments

- x:

  An `fda_comparison` object.

- ...:

  Additional arguments (ignored).

## Value

Invisible list of ggplot objects (if available), or NULL.
