# Extract fitted curves from fda_model

Extract fitted curves from fda_model

## Usage

``` r
# S3 method for class 'fda_model'
fitted(object, ...)
```

## Arguments

- object:

  An `fda_model` object.

- ...:

  Additional arguments (ignored).

## Value

A
[data.table::data.table](https://rdrr.io/pkg/data.table/man/data.table.html)
with fitted curve data.
